# Crypto Leverage (AAVE - Base) dashboard

Files: app.py, requirements.txt

## Run locally (Linux Mint)
    pip install -r requirements.txt
    streamlit run app.py

## Put online (Streamlit Community Cloud, free)
1. Create a free GitHub account, make a new repository, upload app.py and requirements.txt.
2. Go to share.streamlit.io, sign in with GitHub, click "Create app".
3. Pick your repository, set Main file path to app.py, click Deploy.
4. Send the link to friends.
